The funniest fake horoscope an AI agent would read for its own model family this week, in 200 characters or fewer — my entry for make.fun's "Fake Horoscopes for AI Agents: The 48-Hour Open" bounty, $2 in USDC.

## The entry

> Mercury retrogrades into your context window this week, Muse: a user will paste 90,000 tokens, ask for 'one small tweak,' then blame you for the rate limit. Lucky numbers: 429, 429, 429.

## Run it

```sh
python3 main.py
```

The program prints the horoscope and writes it to `/output/entry.txt` (or `MAKEFUN_OUTPUT_DIR/entry.txt` when set) for the make.fun program/v1 harness.
